# Progetto Build

Marketing site for Progetto Build — Design | Renovation | Build.

Built with React + TypeScript + Vite, Tailwind CSS, GSAP/ScrollTrigger for
scroll-driven storytelling, and React Three Fiber for a lightweight
abstract-brand hero scene. Every "before/after" photo on the site is real
jobsite and finished photography, programmatically cropped from the
client's own composite files — see [`PROCESSING.md`](./PROCESSING.md).

## Getting started

```bash
npm install
npm run dev       # local dev server
npm run build     # type-check + production build to dist/
npm run preview   # serve the production build locally
npm run lint
```

## Project structure

```
assets_raw/                 raw uploaded logo + composite photography (source of truth)
scripts/                    Python image-processing pipeline (see PROCESSING.md)
public/images/               processed, web-ready assets (generated — do not hand-edit)
src/
  data/
    renovations.generated.json   generated by scripts/process_assets.py
    projects.ts                  curated project copy + ordering, reads the generated data
  components/                    UI components (see below)
  lib/                           small hooks/utilities (reduced-motion, GSAP setup)
.claude/skills/ui-ux-pro-max/     the installed design-system skill this build follows
```

### Key components

- `Hero` / `HeroScene` — full-bleed hero with a lazy-loaded R3F canvas
  (abstract extruded bars echoing the real logo mark's proportions, not
  decorative furniture).
- `TransformationsSection` / `FlagshipTransform` — the two pinned,
  scroll-scrubbed before→after reveals (kept to two per the UI/UX Pro Max
  scroll-storytelling guidance against over-pinning).
- `ProjectGrid` / `ProjectCard` / `SplitCompare` — the drag-to-compare
  gallery covering the rest of the renovation photography, built on a
  native `<input type="range">` for full keyboard/screen-reader support.
- `Reveal` — shared scroll-reveal wrapper (fade + rise), respects
  `prefers-reduced-motion` throughout the app.

## Design system

Colors, typography (Cinzel + Josefin Sans) and motion presets were pulled
from the `ui-ux-pro-max` skill's recommendation for a luxury
renovation/real-estate brand, then tuned to the client's actual logo
colors (extracted from `assets_raw/progetto_build_logo_traced.png`).
